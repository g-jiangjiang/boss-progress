# BOSS 记录助手（Tampermonkey）

用于在 BOSS 直聘网页端记录和展示求职相关数据。数据保存在浏览器本地 IndexedDB，支持多账号区分、搜索、CSV 导入/导出。

当前脚本版本：`0.6.5`

## 功能概览

- 投递记录：已沟通、已投递、已面试、已收藏
- 屏蔽公司：简历自动屏蔽、手动屏蔽、智能屏蔽
- 拉黑 Boss：记录 Boss、公司和职位信息
- 多账号区分：每条数据都带账号标识
- 页面打标：职位列表、职位详情、聊天页
- 搜索和筛选：支持文本搜索、状态筛选、账号筛选
- CSV 导入 / 导出：按当前面板类型导入导出
- 当前类型清空：只清空当前账号、当前类型的数据
- 面板可拖动，可从边缘拖拽调整大小

## 安装

1. 安装浏览器扩展 Tampermonkey。
2. 打开安装地址：[boss-progress.user.js](https://raw.githubusercontent.com/g-jiangjiang/boss-progress/main/boss-progress.user.js)。
3. Tampermonkey 会自动弹出安装/更新页面，点击安装或更新。
4. 打开 BOSS 直聘网页，右下角出现「BOSS记录」面板即生效。

## 面板说明

面板顶部有三个数据视图：

- `投递`：投递进度数据
- `屏蔽公司`：隐私保护里的屏蔽公司数据
- `拉黑Boss`：隐私保护里的拉黑 Boss 数据

面板会根据当前页面自动切换视图。例如打开 `type=bossBlacklist` 页面时会自动选中「拉黑Boss」。

## 投递记录

### 同步页面

仅建议在这些页面点击「同步页面」：

- `https://www.zhipin.com/web/geek/recommend?tab=1&page=1&tag=5`：已沟通
- `https://www.zhipin.com/web/geek/recommend?tab=2&page=1&tag=3`：已投递
- `https://www.zhipin.com/web/geek/recommend?tab=3&page=1&tag=2`：已面试
- `https://www.zhipin.com/web/geek/recommend?tab=4&sub=1&page=1&tag=4`：已收藏

### 页面打标

- 同公司同岗位匹配：显示为岗位状态，例如「已投递 java」
- 同公司但不是同岗位：显示为公司级状态，并在悬停提示里展示曾投递岗位
- 多账号都有记录时：会按账号分别展示
- 聊天页只展示已投递、已面试，不展示仅沟通状态

## 屏蔽公司

同步页面：

`https://www.zhipin.com/web/geek/privacy-set?type=shieldCompany`

支持三类来源：

- 简历自动屏蔽
- 手动屏蔽
- 智能屏蔽

使用方式：

1. 打开屏蔽公司页面。
2. 切到面板的「屏蔽公司」。
3. 可直接点击「同步页面」同步当前页面可见内容。
4. 对于完整列表，需要在 BOSS 页面点击「查看更多」或「批量管理」，脚本会采集弹窗中可见/滚动加载出来的数据。

注意：BOSS 的列表可能是虚拟滚动，页面显示的总数和脚本实际可采到的数量可能不完全一致。建议以搜索能否命中具体公司为准。

## 拉黑 Boss

同步页面：

`https://www.zhipin.com/web/geek/privacy-set?type=bossBlacklist`

记录字段包括：

- Boss 名称
- 公司名称
- 职位/身份信息
- 来源账号

打开页面后，面板会自动切到「拉黑Boss」。点击「同步页面」可同步当前可见列表。

## 搜索与筛选

- 搜索框会根据当前视图搜索对应内容。
- 投递视图支持状态筛选。
- 所有视图都支持账号筛选。

搜索示例：

- 投递：公司名、岗位名、状态
- 屏蔽公司：公司名、来源类型
- 拉黑 Boss：Boss 名、公司名、职位

## CSV 导入 / 导出

导出按当前视图执行，只导出当前账号数据。

文件名前缀：

- 投递：`boss-progress-账号-YYYYMMDD-HHmmss.csv`
- 屏蔽公司：`boss-company-blacklist-账号-YYYYMMDD-HHmmss.csv`
- 拉黑 Boss：`boss-boss-blacklist-账号-YYYYMMDD-HHmmss.csv`

CSV 带 UTF-8 BOM，Excel 直接打开中文不应乱码。

导入说明：

- 脚本会按表头自动识别投递、屏蔽公司、拉黑 Boss。
- 如果导入文件的账号与当前账号不同，会映射到当前账号，方便按账号管理。

## 清空数据

「清空」按钮只清空：

- 当前账号
- 当前视图

例如当前视图是「屏蔽公司」，按钮会显示为「清空屏蔽公司」，只删除当前账号的屏蔽公司数据，不会删除投递记录和拉黑 Boss。

清空前会弹窗确认并显示将删除的条数。

## 本地数据

数据仅保存在浏览器本地 IndexedDB，不会上传到任何服务器。

如果更换浏览器、清理浏览器数据或更换浏览器配置目录，本地记录可能丢失。建议定期导出 CSV 备份。

## 注意事项

- BOSS 直聘页面结构经常变化，脚本依赖 DOM 解析，可能需要随页面更新维护。
- 脚本已移除面板里的接口采集按钮，默认不拦截接口响应，降低页面异常和风控风险。
- 如果页面刷新后没有标记，先确认当前账号是否一致，再尝试搜索面板内是否有对应记录。
- 如果某类数据同步数量和页面总数不一致，优先用搜索验证具体公司/Boss 是否已采到。
